# Peak Path Sales Dashboard

## Overview
The Peak Path Sales Dashboard is an interactive dashboard designed to help business users monitor leads, track sales progress, and understand conversion performance.
It provides a quick overview of lead activity, booked calls, won deals, revenue, and sales performance through key metrics and interactive charts.

## Dashboard Features

- **Key Performance Indicators (KPIs):** View total leads, total booked calls, won deals, total revenue, lead-to-booked conversion, and booked-to-won conversion.
- **Lead Funnel:** Understand how leads are distributed across sales stages.
- **Leads by Source:** Compare the number of leads generated by different sources.
- **Close Rate by Representative:** Compare conversion performance across sales representatives.
- **Interactive Filters:** Filter results by lead source, sales representative, stage, and date range.
- **Refresh Data:** Reload the dashboard data when updates are available.

## How to Use the Dashboard

1. Review the KPI cards for a quick overview of sales performance.
2. Explore the charts to understand lead distribution, lead sources, and representative performance.
3. Use the filters to focus on a particular source, representative, stage, or time period.
4. Select **Reset Filters** to return to the unfiltered view.
5. Hover over chart elements to view additional details.

## How to Update the Dashboard Data

The dashboard uses a CSV file named `leads.csv` as its data source.

To update the dashboard with new lead data:

1. Update the `leads.csv` file on your computer with the latest data.
2. Open the GitHub repository and navigate to `data/leads.csv`.
3. Replace the existing file with the updated CSV, keeping the same filename and location.
4. Commit the change to the repository.
5. Wait for GitHub Pages to finish publishing the update, then refresh the dashboard in your browser.

The dashboard will load the updated data when the page is refreshed. If the old data still appears, wait a little longer and refresh again.

**Important:** Keep the CSV column names and data format consistent with the existing file. Use fictional or appropriately anonymized data when sharing this public dashboard.

## Metric Definitions
- Total Leads - Total number of lead records included in the current view. 
- Total Booked Calls - Count of leads in the Call Booked, No Show, Won, or Lost stages. 
- Won Deals - Number of leads in the Won stage. 
- Total Revenue - Sum of valid recorded deal values for the included leads, regardless of stage. 
- Lead-to-Booked Conversion - Total booked calls divided by total leads, expressed as a percentage. 
- Booked-to-Won Conversion - Won deals divided by total booked calls, expressed as a percentage. 

## Business Rules and Notes

- No Show, Won, and Lost records are included in Total Booked Calls, along with Call Booked records.
- Revenue reflects recorded deal values; it does not necessarily represent payments received.
- Leads with blank or unrecognized stages remain visible in the lead funnel but are not counted as booked calls or won deals unless their stage matches the defined categories.
- Source and representative names are grouped without distinguishing capitalization or surrounding spaces.
- Blank sources are grouped under Unknown Source.
- Blank or Unassigned representatives are excluded from the Close Rate by Representative chart.
- Conversion rates are shown as unavailable when their denominator is zero.
- KPI values and charts respond to the active filters.
